# 🏎️ F1 Stats Tracker

A responsive web application built to track Formula 1 standings and display a countdown timer for the upcoming Grand Prix.

## 🔗 Live Demo

[Click here to view the live application](https://cmoha15.github.io/f1-stats/)

## ⚠️ Important Note on Data Updates

Please note that this application uses the Jolpi Ergast API, which does **not** provide live real-time data during a race. Standings and race results are typically updated **24 hours (one full day) after** the conclusion of a Grand Prix.

## ✨ Features

- **Current Standings:** Displays the latest official F1 driver and constructor standings.
- **Race Countdown:** Dynamic countdown timer for the next Grand Prix.
- **API Integration:** Fetches racing data asynchronously.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (DOM Manipulation & Fetch API)
- [Jolpi Ergast F1 API](https://jolpi.ca/ergast/)
